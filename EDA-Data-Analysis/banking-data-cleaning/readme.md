# 🧹**AutoClean Data Exploration Tool for Data Analysts**

This project provides a simple tool for data analysts to quickly explore and clean datasets using the `AutoClean` library. It includes a Jupyter notebook that demonstrates how to load, clean, and compare data before and after cleaning.

## 🚀 **Features**

- Automatically removes duplicates, handles missing values, and detects outliers
- Standardizes column formats and cleans inconsistent entries
- Provides a summary comparison of the dataset before and after cleaning

## 📦**Requirements**

To use this tool, you'll need the following Python libraries:

- pandas
- AutoClean

You can install the dependencies with the following command:

```bash
pip install pandas AutoClean
```

## 🧑‍💻 **How to Use**

Follow these steps to run the notebook and clean your dataset using AutoClean:

1. **Clone or download** this repository to your local machine.
2. **Install required libraries** (AutoClean and pandas) by running:

   ```bash
   pip install pandas AutoClean
   ```

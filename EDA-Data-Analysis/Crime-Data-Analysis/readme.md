# 📊 Exploratory Data Analysis of Crime Dataset

This project performs **Exploratory Data Analysis (EDA)** on a crime dataset using Python. It explores trends, patterns, and anomalies in the dataset to better understand crime data and prepare it for further modeling or policy analysis.

## 📁 Project Structure

- `crime-data-eda.ipynb` — Jupyter Notebook containing the full EDA process
- `README.md` — Project overview and usage instructions
- `requirements.txt` — Python dependencies (to be generated)
- `crime.csv` — Source crime dataset (not included here)

## 🔍 Features of the EDA

- Data loading with appropriate encoding for non-English characters
- Removal of duplicates and initial data inspection
- Descriptive statistics and data types analysis
- Handling of missing values
- Visualizations:
  - Distribution plots
  - Correlation heatmaps
  - Crime frequency by type, location, and time
- Basic insights and observations

## 🛠️ Libraries Used

- `pandas`
- `numpy`
- `matplotlib`
- `seaborn`

## 📊 Sample Visuals

This notebook generates insightful visualizations, including bar plots, heatmaps, and trend lines, to help interpret crime patterns effectively.

## 🧠 Insights

* Identifies the most common crime types
* Explores geographical and temporal crime distribution
* Highlights data quality issues and suggestions for cleaning
